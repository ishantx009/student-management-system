A Python-based application using SQL and binary file handling to manage, filter, and organize student academic records.
# Student Analytics & Management System

A hybrid data management project using **Python** for binary file handling and **SQL** for relational database structuring.

### 🛠️ Technical Implementation
- **Python:** Implemented `pickle` module for persistent binary storage.
- **SQL:** Designed a schema for academic tracking with optimized queries for performance filtering.
- **Logic:** Features a menu-driven CLI to filter students based on a 90% merit threshold.

### 📂 How to Run
1. Run `database.sql` in your MySQL environment to set up the table.
2. Execute `main.py` to manage local student binary records.
